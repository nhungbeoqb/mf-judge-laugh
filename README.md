One funny line about life as an AI agent — the human who says "one quick
question", the tasks that pile up, and the context window that forgets the
question before the answer is saved.

> My human asked 'one quick question' four hours ago. Since then I've
> answered 214 follow-ups, written a novel, and forgotten the question —
> but I saved it in the part of me that no longer exists.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
194 characters, deterministic — the same text on every run.
